# QQQ / QLD 动态滚仓策略 —— 回测与报告流水线

基于技术指标(MACD / RSI / Supertrend + 250 日趋势闸门)在 **QQQ半仓 → QQQ全仓 → QQQ+QLD → QLD全仓 → 现金** 之间自动滚动切换仓位的策略,附完整历史回测与交互式 HTML 报告。

---

## 一、文件清单

| 文件 | 作用 | 产物 |
|---|---|---|
| `1_prepare_data.py` | 下载 QQQ/QLD/^IRX,合成 2006 前 QLD,拼接价格 | `prices.csv` |
| `2_backtest.py` | 计算指标、跑 V4.2 策略回测、导出结果 | `results.json` |
| `3_generate_report.py` | 把结果渲染成自包含交互式网页 | `qqq_qld_report.html` |
| `daily_check.py` | 盘后算今日目标敞口,给"持有/调仓"建议 | 打印到终端 |
| `README.md` | 本说明 | — |

> 附:`opt.py` 为参数稳健性 / 样本内外验证脚本(可选,见第五节)。

## 二、运行方法

```bash
# 依赖(只需一次)
pip install yfinance pandas numpy

# 按顺序运行(三个脚本都把产物写到脚本所在目录)
python 1_prepare_data.py      # 联网下载,约 10 秒

```

数据每天更新:重跑这三步即可刷新到最新交易日。

## 三、策略逻辑(V4.2)

决策链,**信号在 T 日收盘生成、T+1 执行(无未来函数)**:

1. **宏观闸门** —— 收盘价 vs **250 日均线**,决定多空大方向。
2. **空头区(价 < 250日线)**
   - **强空头**(MACD 线 < 0 **且** Supertrend 空头)→ **100% 现金**(买短端国债)。
   - 否则**温和回调** → **QQQ 半仓(0.5x)** + 半仓现金。
3. **多头区(价 > 250日线)** —— 动量打分(0~4):`Supertrend多头 + MACD柱>0 + MACD线>0 + RSI>50`
   - 0~2 → **QQQ全仓(1.0x)**,3~4 → **QQQ+QLD(1.5x)**。
   - **V4.2 起最高档为 1.5x**(`MAX_EXPOSURE=1.5`,去掉原 QLD全仓 2x 档——经验证 2x 不赚风险溢价,砍掉零代价)。
   - 上 1.5x 还需**熔断许可**:250日线上行 **且** 20日年化波动率 < 40%。
4. **波动率目标(核心风控)** —— 最终净敞口 = 档位敞口 × `min(1.0, 20% ÷ 20日实际年化波动率)`,0~2x 封顶(只降不升)。
   波动飙升时自动砍杠杆,是压低回撤的关键。
5. **执行细节** —— 净敞口按 0.05 档、连续 3 日确认;再设 **0.10x 死区**(`DEADBAND`,目标偏离当前持仓 <0.10x 则不调仓,与实盘一致);现金按 ^IRX 利率计息;每次调仓计 5bp 单边成本。全周期约 13 次调仓/年。

因为有波动率目标,实际净敞口是 **0(现金)~ 2.0x** 连续变化的,不是死板的四档。

## 四、回测结果(1999-03 ~ 至今,含成本)

| 方案 | 年化 | 总收益 | 最大回撤 | Calmar | 夏普 |
|---|---|---|---|---|---|
| **V4.2 策略** | **12.4%** | **2306%** | **−30.0%** | **0.41** | 0.71 |
| 买入持有 QQQ | 10.7% | 1516% | −83.0% | 0.13 | 0.51 |
| 买入持有 QLD | 10.2% | 1322% | −98.8% | 0.10 | 0.45 |

**用比 QQQ 更低的回撤(−30% vs −83%),拿到更高的总收益。** 2006 年后(全真实 QLD 数据)子区间 Calmar 0.51,全场最优。含 0.10x 死区后年化约 13 次调仓,平均净敞口 0.95x。

> **再平衡说明:** 组合在档位持有期内**不做再平衡**——QQQ/QLD 权重随行情自由漂移,只有当策略发出换档信号时才调仓(按实际成交计 5bp 成本)。这与实盘操作一致,也是换手最低的方式。测试表明:相比"每日再平衡回目标",两者长期结果差异 < 0.03pp,可忽略。

## 五、如何进一步调参(避免过拟合)

所有可调参数集中在 `2_backtest.py` 顶部的 `CONFIG` 区。调参前请读这几条:

- **只在样本内找、拿样本外验**:用 `opt.py` 可看每组参数在"训练段(≤2012)/验证段(2013+)"的分别表现。两段都好才可信。
- **找高原、别找尖峰**:好参数应是"邻近值都不错"的平缓区。已验证 `SMA_LEN` 在 250/300 都好(故选 250);`VOL_TARGET` 在 0.14~0.25 之间结果都相近(不敏感)。
- **少调、只调有逻辑的**:把多个"单独最优"的参数一起堆叠,往往**不如只改一个**——这就是过拟合。
- **有物理上限**:用杠杆扛过 2000/2008 两次崩盘又想要高收益,数学上做不到;−32% 已接近杠杆策略在那两次崩盘下的实际地板。

`opt.py` 运行:`python opt.py`(需先有 `prices.csv`),会打印 volt×vcap 网格 + 各参数 1D 敏感性。

## 五之二、每日盘后执行(daily_check.py)

```bash
python daily_check.py                 # 看今日目标敞口与持仓构成(QQQ%/QLD%/现金%)
python daily_check.py --current 0.66  # 传入当前净敞口,输出 持有 / 调仓 建议
```

执行纪律(避免被日间零点几的波动带着频繁交易):

- **必调**:目标跨越关键边界——从"投资↔清仓"或"无杠杆↔动用 QLD 杠杆(1.0 线)"。
- **同区微调**:目标与当前敞口差 **≥ 0.10x** 才调,否则持有。
- 天天看没问题(回测里每日检查回撤最浅),真正动手全年约 12–15 次,平均两三周一次。

## 六、数据与方法说明

- **数据源**:yfinance 的复权收盘价(QQQ 含高/低价用于 Supertrend 的真实 ATR)。
- **合成 QLD**:QLD 2006-06 上市,之前用 `2×QQQ日收益 − (0.95%费率 + 短端利率)/252` 合成。与真实 QLD 重叠期日收益相关性 **0.996**,CAGR 偏乐观约 **0.8%/年** —— 即 1999~2006 段(含互联网泡沫)真实表现可能比回测略差。2006 年后全部为真实数据。
- **无风险利率**:^IRX(13 周美债),既作 QLD 融资成本代理,也作现金收益。
- **夏普**用 rf=0 计算;Calmar = 年化收益 / |最大回撤|。
